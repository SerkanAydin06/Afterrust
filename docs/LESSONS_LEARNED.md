# Afterrust — Öğrenilen Dersler
Bu dosyaya yalnız doğrulanmış teknik sonuçlar eklenir.

## Kayıt formatı
- Tarih, görev/PR bağlantısı
- Problem ve kanıt
- Denenen yöntem
- İşe yarayan çözüm ve test
- Tekrar kullanımı / maliyet kazanımı (ölçüldüyse)
- Yanlış çıkan varsayım

Henüz uygulama yapılmadı; kayıt yok.
